## 告警修复

上游文件已从 CRT 头文件获得 EINVAL，随后再次定义为 ERROR_INVALID_PARAMETER。Windows 编译适配器只对该文件创建临时副本，在定义前增加 undef 防护，保留原有 Windows 错误码映射及 Apache-2.0 文件头；原始依赖缓存不变，副本编译后清理。

`scripts/msvc-cl.mbtx` 承担处理逻辑；小型 C 启动器只转发 Unicode 命令行到 MoonBit 脚本，兼容编译和归档驱动。生成的可执行文件位于忽略的 `_build`，没有提交或分发 MSVC 二进制。

验证入口启用 `/we4005`，将宏重定义视为错误。真实编译探针确认：修复后的源文件编译成功、错误码映射保持一致、其他文件的宏重定义仍会失败、带空格的参数可以转发、原始缓存文件未变化。此次没有使用 `/wd4005` 或 pragma 禁用诊断。

修复范围是本项目提供的 Windows 构建及 CLI 入口；其他项目直接编译官方 async 0.22.5 仍可能收到原告警，不能据此宣称上游已发布修复版。待上游正式发布后可移除此兼容处理。
