## 选题边界

moon-ipp 实现 IPP 二进制协议、打印选项预检与任务生命周期。文本格式化工具不提供这些能力，因此功能不重合。项目复用 core 和 async，不重复建设 HTTP、TLS、文件系统基础库。

用户提供的 ELK 项目只作为申报格式样本，自动图布局选题因社区已有实现而排除。另有 Jsonnet 和 Cap'n Proto 方向虽然 Mooncakes 检索未命中，但公开 GitHub 已找到对应 MoonBit 项目，因而排除。

比赛说明分析以参赛者粘贴的正文为依据；飞书在线页面正文未成功取得，不宣称已核验在线页面的更新。查重记录不是主办方审核或报名通过证明。
